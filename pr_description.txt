🚨 Severity: MEDIUM
💡 Vulnerability: Overly permissive CORS configuration allowing arbitrary cross-origin requests (`Access-Control-Allow-Origin: *`).
🎯 Impact: Potentially allows unauthorized origins to read telemetry or dashboard data if the backend was ever exposed to authenticated sessions, or could be used to bypass same-origin policies.
🔧 Fix: Removed the `Access-Control-Allow-Origin: *` wildcard from `STATIC_SECURITY_HEADERS` and fallback headers in the asset handler, relying strictly on same-origin policies. Telemetry ingestion operates via a 1x1 image pixel and the API acts as a same-origin proxy, so cross-origin requests are not needed.
✅ Verification: Verified syntax (`node -c`). Verified that the `Access-Control-Allow-Origin` wildcard was successfully stripped from the codebase.
