💡 What:
Extracted the `parseKvInt` utility function from the local scope of the `handleApiStats` request handler to the outer module scope in `src/api.js`.

🎯 Why:
Defining utility closure functions inside the main request handler causes V8 to allocate closure memory for these functions on every single request. In high-throughput API endpoints, this creates unnecessary Garbage Collection (GC) pressure.

📊 Impact:
Significantly reduces memory allocations and Garbage Collection (GC) overhead on hot API paths.

🔬 Measurement:
Run `node -c src/api.js` and `npm run test` (if available) to ensure syntax is valid and no regressions are introduced. Monitor Cloudflare edge CPU time for improvements.
