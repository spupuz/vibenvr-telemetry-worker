## 2024-06-25 - Dynamic States in Vanilla JS Dashboards
**Learning:** When building visual dashboards in vanilla JS without frontend frameworks, dynamic states like loading spinners (`#loader`) and error containers (`#error-msg`) often appear and disappear through DOM manipulation or CSS `display` toggling. Screen readers do not automatically announce these state changes unless explicitly told to do so. Furthermore, decorative SVG icons used heavily in dark/light mode toggles and footer links can create redundant or confusing noise for screen reader users if not hidden. Custom focus styles are often missed for custom buttons or links when native outlines are removed or overridden.
**Action:** Always add `role="status"` and `aria-live="polite"` to loading containers, and `role="alert"` and `aria-live="assertive"` to error containers that will be dynamically toggled via JS. Add `aria-hidden="true"` to purely decorative SVG icons. Ensure custom buttons (`.theme-btn`, `.retry-btn`) and links (`.footer-link`) have a `:focus-visible` state explicitly defined in CSS to support keyboard navigation.
